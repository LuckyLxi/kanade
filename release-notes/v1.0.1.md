## 新功能

- 听歌识曲可以识别本机正在播放的声音，识别过程中可以暂停
- 播放服务意外退出后自动恢复，重启应用会回到上次的播放进度
- 搜索页重新设计：新增「综合」结果、最近搜索记录，分类之间可以滑动切换
- 最近播放页重新设计，支持分类滑动切换，搜索框常驻
- 发现页改用滑动分段切换，打开播放页时自动收起键盘
- 歌手页的分类标签支持左右滑动切换，带过渡动画
- 歌曲操作菜单重新设计，并显示评论数
- 睡眠定时器面板重新设计，弹出面板的动画更顺滑
- 迷你播放器按下时有弹性缩放反馈
- 列表进入和加载更多时有入场动画
- 底部标签栏拖动时的摆动和越界回弹手感优化
- Android 页面切换时左侧保持圆角
- Android 上按两次返回键才会退出应用
- Windows 安装程序支持简体中文

## 问题修复

- 随机播放时「上一首」现在按播放历史回退
- 重启后恢复的电台会继续自动补充歌曲
- 修复播放页背景和封面阴影的色带
- 修复正在播放列表底部抖动
- 修复播放页底部按钮宽度不一导致的布局跳动
- 登录设备按平台注册，退出登录时会同时移除该设备
